# @qdoc/db

Initial PostgreSQL + Prisma domain package for the QDoc private-beta rebuild.

## Included in `v1-domain-schema`

- organization and staff membership
- site and optional department structure
- queue and ticket lifecycle roots
- invitation and email auth challenge scaffolding
- notification and outbox persistence
- audit log and ticket event history

## Not included yet

- queue projections/read models
- session storage
- worker processors
- application services
